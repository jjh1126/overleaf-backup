\begin{abstract}

Online VNE에서는 현재 도착한 VNR을 수용하는 것뿐만 아니라, 향후 도착할 요청을 위해 잔여 substrate resource의 활용 가능성을 보존하는 것이 중요하다. 기존 방법들은 주로 잔여 자원의 절대량이나 부하 분산을 고려하지만, 남은 자원이 향후 VNR을 구성하는 다른 자원과 실제로 결합될 수 있는 정도를 직접적으로 정량화하지 않는다.

본 논문에서는 잔여 자원량과 external connectivity를 결합하여 잔여 자원의 활용 가능성을 정량화하는 External-Connectivity-based Fragmentation (ECF) metric을 제안한다. ECF는 node embedding과 link routing에서 요구되는 서로 다른 자원 결합 관계를 반영하여 node와 link에 대해 각각 정의된다.

또한 임베딩 전후의 fragmentation 변화에서 자원 자체가 소비되는 효과와 자원 소비 이후 남은 자원의 connectivity가 저하되는 효과를 분리하고, 후자를 induced fragmentation cost로 정의한다. ECF를 기존 online embedding framework에 통합한 VNE-ECF-LB는 이 비용을 load-balancing cost와 함께 node candidate 및 path selection에 반영하여, 현재 요청의 실행 가능성과 향후 잔여 substrate resource의 활용 가능성을 함께 고려한다.

실험 결과, VNE-ECF-LB는 synthetic Erdős–Rényi substrate의 연결 밀도와 실제 Topology Zoo network의 workload가 변화하는 다양한 조건에서 비교 기법보다 일관되게 높은 VNR acceptance ratio를 보였다. 일부 조건에서는 revenue-to-cost ratio 측면의 trade-off가 관찰되었으나, 더 많은 VNR을 지속적으로 수용하면서 substrate resource를 활용함으로써 online VNE의 장기적인 수용 성능을 향상시켰다.

\end{abstract}

\section{Introduction}
\label{sec:introduction}

% VNE 의 배경과 정의
Modern network infrastructures must serve diverse tenants and applications simultaneously. These services range from latency sensitive real time traffic to bandwidth intensive data transfers, and their resource requirements are often heterogeneous. Network virtualization addresses these requirements by abstracting physical infrastructure into virtual resources. Each service request is commonly modeled as a virtual network request (VNR) with node and link resource requirements. Mapping a VNR onto the substrate network requires node embedding and virtual link routing, a process known as virtual network embedding (VNE)~\cite{satpathy2025virtual}.

% Dynamic VNE 의 어려움 + 파편화 문제로 인한 미래 자원 활용성
In practical deployments, VNE operates in a dynamic setting where VNRs arrive and depart over time. Each embedding decision must therefore be made online under changing substrate resource availability. This setting is challenging for two reasons. First, VNE is computationally intractable: the decision version is NP-complete, and optimization variants are NP-hard~\cite{rost2020hardness}. Practical algorithms therefore rely on heuristic strategies rather than globally optimal solutions. Second, each locally feasible decision changes the residual substrate state available to future requests. As VNRs are repeatedly embedded and released, residual resources may become distributed in ways that make future embeddings difficult, even when sufficient aggregate capacity remains. This degradation of future resource usability is commonly referred to as resource fragmentation~\cite{fischer2013virtual}. A locally feasible embedding may therefore serve the current request while increasing the likelihood that later requests are rejected.

% 기존 방법의 한계
Existing online VNE heuristics manage residual capacity, path feasibility, and embedding cost during node and link routing. However, their control granularity is mainly limited to individual substrate nodes, adjacent link sets, candidate paths, or aggregate load balancing objectives. These approaches do not explicitly quantify resource fragmentation in the residual substrate state.

VNR은 node와 link가 결합된 그래프 구조이므로, 특정 substrate resource에 충분한 잔여 용량이 존재하더라도 주변 자원과 함께 향후 요청을 구성하기 어렵다면 그 자원의 실질적인 활용 가능성은 낮다. 따라서 Resource Fragmentation 은 잔여 자원의 양과 활용 가능성을 함께 고려하여 평가할 수 있다. 본 논문에서는 자원의 활용 가능성을 external connectivity 로 정의하고, 이를 위해 잔여 자원량과 결합한 External-Connectivity-based Fragmentation (\ecf) metric을 정의한다.

Node embedding과 link routing은 서로 다른 형태의 자원 결합을 요구한다. Substrate node의 CPU는 인접 substrate link의 bandwidth를 통해 다른 자원과 연결되어야 하며, substrate link의 bandwidth는 다른 link와 연속적으로 연결되어 path 또는 graph를 구성할 수 있어야 한다. 따라서 본 논문은 동일한 external-connectivity 관점에 대하여, node와 link가 VNE에서 수행하는 역할에 맞추어 fragmentation을 각각 정의한다.

또한 임베딩 전후의 fragmentation score 변화에는 직접적인 자원 소비와 잔여 자원의 connectivity 저하가 동시에 포함된다. 고립된 자원이 단순히 소비됨에 따라 fragmentation score가 감소하는 경우와, 적절한 임베딩을 통해 잔여 자원의 고립을 방지하여 fragmentation을 낮추는 경우는 구분할 필요가 있다. 본 논문은 두 효과를 분리하고, 자원 소비 이후 남은 자원의 connectivity 저하로 인해 발생하는 부분만을 induced fragmentation cost로 정의한다. \ecfvne{}는 이 비용을 기존의 load-balancing cost와 함께 node candidate 및 path selection에 반영함으로써 현재 VNR을 수용하는 동시에 이후 요청에 사용할 수 있는 substrate resource의 활용 가능성을 보존한다.

이와 같은 관점에서 본 논문의 주요 기여는 다음과 같이 요약할 수 있다. 잔여 자원의 절대량이 아니라 다른 자원과의 결합 가능성을 중심으로 resource fragmentation을 평가하고, external connectivity에 기반한 통일된 \ecf{} metric을 node와 link에 각각 특수화한다. 또한 induced fragmentation을 직접적인 자원 소비 효과와 분리하여 online VNE의 node 및 path selection에 반영하는 \ecfvne{}를 제안한다.


\section{Related Work}
\label{sec:related_work}

\subsection{Resource- and Topology-Aware VNE}

Conventional VNE heuristics commonly prioritize candidate substrate nodes according to residual CPU, residual bandwidth, node degree, centrality, or combinations of these quantities. PageRank-inspired and other resource-aware node-ranking heuristics use resource and topology information to estimate the suitability of substrate nodes, followed by virtual link routing through shortest paths or $k$ shortest paths~\cite{cao2017novel,hashmi2020vne}. Other studies use betweenness centrality, closeness centrality, degree, strength, and multiple topology attributes to guide node embedding~\cite{ding2015virtual,guler2016closeness,feng2014topology}. More recent multi-criteria methods further combine several node attributes into a single ranking score. NORD combines entropy-based weighting with TOPSIS to rank substrate nodes~\cite{tg2023nord}, while simplified ELECTRE evaluates candidate substrate nodes using multiple node metrics and constraints~\cite{zhang2018virtual}. These approaches primarily use resource and topology information to estimate candidate-node suitability for the current embedding decision rather than to characterize fragmentation of the residual substrate state.

Another line of work coordinates node embedding and link routing because independently selected node embeddings can lead to infeasible or costly link routings. Coordinated approaches therefore solve the two mapping operations jointly or through coupled stages~\cite{chowdhury2012vineyard,lu2023performance,nguyen2022toward}. Related methods extend this consideration by incorporating congestion, energy consumption, latency, or path characteristics into embedding decisions~\cite{pham2019congestion,zheng2017link,yan2019latency}. Such coordination determines how node and link allocation decisions interact and can improve the feasibility or cost of an embedding. However, coordination and resource fragmentation address different aspects of VNE: coordination determines how an embedding is constructed, whereas fragmentation metrics characterize the usability of the residual resources left by that embedding.

Load-balancing approaches address another related aspect by discouraging excessive resource concentration on particular substrate nodes or links~\cite{gong2014toward,shanbhag2015vhub,li2022load}. Some load-balancing methods additionally use global resource information or neighboring bandwidth when evaluating node-embedding potential. These objectives seek a balanced distribution of substrate utilization. Resource balance and resource fragmentation, however, are not equivalent. From the fragmentation perspective adopted in this paper, the relevant question is whether a residual resource can still be used together with the other resources required by a future mapping operation, rather than only whether residual resources are evenly distributed across the substrate network. This distinction does not exclude load balancing; instead, this paper retains load balancing separately through the resource-usage term $C_{\mathrm{use}}$, while modeling fragmentation cost as a distinct objective.

\subsection{Survivable VNE Under Substrate Failures}

Survivable VNE addresses service availability under substrate failures. Prior studies reserve backup paths or redundant node and link resources, construct backup topologies, or remap affected virtual components after failures~\cite{liao2014survivable,chowdhury2016dedicated,liu2017scheme,zheng2019heuristic,sun2011framework,zhu2014heuristic}. Shahriar et al.~\cite{shahriar2019virtual} formulate Connectivity-aware Virtual Network Embedding (CoViNE), which guarantees VN connectivity under multiple substrate link failures without requiring full bandwidth protection. CoViNE uses VN augmentation and disjointness requirements to preserve connectivity after failures. Survivable VNE concerns whether an embedded VN can continue to satisfy a survivability requirement after substrate failures, whereas this paper considers the usability of residual resources resulting from online embedding decisions under normal operation.

\subsection{Fragmentation-Aware VNE}

The following studies are most closely related to the fragmentation notion considered in this paper. Fragmentation-aware VNE explicitly considers residual resources that become difficult to use despite remaining available. 

Guan et al.~\cite{guan2023multidimensional} study multidimensional resource fragmentation for VNE in MEC systems interconnected by optical networks. For physical nodes, their formulation characterizes fragmentation through imbalanced utilization of computing and wireless resources. For physical links, it identifies unusable or difficult-to-use optical spectrum fragments created under spectrum continuity and consistency constraints. Their bilevel formulation also accounts for the dependency between virtual node embedding and virtual link routing. Thus, their fragmentation model focuses on imbalance among heterogeneous node resources and contiguity of optical spectrum resources, which differs from the CPU--bandwidth resource relationships addressed in this paper. Whereas this paper treats node and link fragmentation as two instances of the same general form $F=R(1-\mathrm{Conn})$, Guan et al. formulate two problems with different characteristics: node imbalance and link spectrum continuity.

Lu and Zhang~\cite{lu2022resource} address a more closely related notion of resource fragmentation. They define the resource fragmentation degree (RFD) for substrate nodes and links based on the observation that the usability of a residual resource depends on surrounding residual resources. For a substrate node, RFD incorporates residual resources of neighboring nodes and paths within a bounded hop count. For a substrate link, RFD incorporates the residual resources of adjacent links and the substrate nodes shared by those links. Their formulation is motivated by an extension of graph connectivity and aggregates these surrounding resource states to quantify the fragmentation degree of each substrate element. This connectivity extension depends on a hop-bounded neighborhood and its associated hyperparameter, whereas the external connectivity used in this paper is justified directly by the boundary cut, equivalently the max-flow between a resource region and its exterior, and requires no hop-count tuning.

The proposed metric shares with RFD the observation that residual resource amount alone is insufficient to characterize future usability. The distinction lies in how the relevant resource relationships are modeled. Rather than deriving a connectivity-inspired fragmentation degree from surrounding nodes and paths, the proposed metric directly follows the resource combinations required by the two VNE mapping operations. For node embedding, it evaluates the residual resource of a substrate node together with the residual resources of its adjacent substrate links, because both are required to support a virtual node and its incident virtual links. For link routing, it evaluates the residual resource of a substrate link together with the adjacent link resources at each of its two endpoints. The two endpoint states are evaluated separately, and the endpoint with lower adjacent-resource availability determines the resulting value because insufficient adjacent resources at either endpoint can limit the use of the substrate link as part of a path.

Accordingly, the proposed metric differs from the reviewed fragmentation metrics not in whether neighboring resources are considered, but in how their relationships are defined. It characterizes residual-resource usability according to the distinct resource combinations required by node embedding and link routing, aiming to identify residual resources that remain available but are difficult to combine with other resources in future VNR embeddings. In addition, the formulation distinguishes the direct resource-consumption effect of an embedding from the connectivity degradation it induces, with the latter represented through the external connectivity metric introduced in the next section.

\section{System Model}
\label{sec:system_model}

We model the substrate network as a weighted undirected graph $G^S=(N^S,L^S)$, where $N^S$ and $L^S$ denote the sets of substrate nodes and substrate links, respectively. For each substrate node $v\in N^S$, we let $c_v$ and $r_v$ denote its initial and current residual CPU capacities, and for each substrate link $e=\{u,v\}\in L^S$, we let $c_e$ and $r_e$ denote its initial and current residual bandwidth capacities. To represent paths and flows for virtual-link routing, we expand each undirected substrate link $\{u,v\}\in L^S$ into two directed arcs $(u,v)$ and $(v,u)$, and we collect these arcs into the set $A^S$.

We represent a VNR as a weighted undirected graph $G^V=(N^V,L^V)$. Here $N^V$ and $L^V$ are the sets of virtual nodes and virtual links, respectively; we let $d_n$ denote the CPU demand of virtual node $n\in N^V$, and $d_l$ the bandwidth demand of virtual link $l=\{n,m\}\in L^V$.

We define the node mapping as $M_N:N^V\rightarrow N^S$. Each virtual node is mapped to exactly one substrate node, and we assume that distinct virtual nodes of the same VNR are mapped to distinct substrate nodes. We use the binary variable $x_{nv}\in\{0,1\}$, where $x_{nv}=1$ indicates that virtual node $n$ is mapped to substrate node $v$. We define the link mapping as $M_L:L^V\rightarrow\mathcal{P}^S$, where each virtual link $l=\{n,m\}$ is mapped to substrate paths connecting $M_N(n)$ and $M_N(m)$. We let $f_{uv}^l\ge0$ denote the bandwidth flow of virtual link $l$ that traverses arc $(u,v)\in A^S$.

We define the complete VNR embedding as $M=(M_N,M_L)$. After applying an embedding $M$, we update the residual resources of substrate nodes and substrate links, respectively, as follows.
\[
r_v(M)
=
r_v-\sum_{n\in N^V}d_nx_{nv},
\qquad \forall v\in N^S,
\]
\[
r_{\{u,v\}}(M)
=
r_{\{u,v\}}
-
\sum_{l\in L^V}
\left(
f_{uv}^l+f_{vu}^l
\right),
\qquad
\forall\{u,v\}\in L^S.
\]
The pre- and post-embedding residual substrate states defined above serve as the basis for computing the \ecf{} metric and the induced fragmentation cost in the following sections.

\section{External-Connectivity-Based Fragmentation Metric}
\label{sec:metric_definition_of_resource_fragmentation}

We now define the External-Connectivity-based Fragmentation (\ecf) metric, which combines residual amount and external connectivity to represent the future usability of a residual resource. The \ecf{} metric uses a common base form for nodes and links, but specializes to reflect the different ways in which each resource combines with other resources in VNE.

\subsection{Base Definition and External Connectivity}
In VNE, the usability of a residual resource depends not only on its amount but also on its combinability with surrounding resources. Let $R$ denote the residual amount and $\mathrm{Conn}$ the normalized external connectivity; we view $R\cdot\mathrm{Conn}$ as the effectively usable portion of the residual resource that can combine with external resources. We accordingly define the fragmentation score as
\[
F=R(1-\mathrm{Conn}).
\]
When $\mathrm{Conn}$ approaches one, the residual resource can be combined with external resources sufficiently and fragmentation is small; in contrast, as external connectivity decreases, the fragmentation score grows for the same residual amount.

To make external connectivity concrete, we consider any $\emptyset\neq A\subsetneq N^S$ and let $\bar A=N^S\setminus A$. We define the boundary link set that connects the region $A$ with its exterior $\bar A$ as
\[
\delta(A)
=
\{\,e=\{u,v\}\in L^S
\mid
u\in A,\ v\in\bar A\,\}.
\]
We define the initial and current bandwidth capacities of this boundary as
\[
B_{\mathrm{cap}}(A)
=
\sum_{e\in\delta(A)}c_e,
\qquad
B_{\mathrm{res}}(A)
=
\sum_{e\in\delta(A)}r_e,
\]
and we define the normalized external connectivity as
\[
\mathrm{Conn}(A)
=
\begin{cases}
\dfrac{B_{\mathrm{res}}(A)}{B_{\mathrm{cap}}(A)},
& B_{\mathrm{cap}}(A)>0,\\[1mm]
0,
& B_{\mathrm{cap}}(A)=0.
\end{cases}
\]
If we connect $A$ and $\bar A$ to a super source and a super sink, respectively, the cut that separates the two regions coincides with $\delta(A)$; the boundary capacity therefore represents the capacity available for region $A$ to connect with its exterior.

Two properties motivate this specific choice of connectivity term. First, $\mathrm{Conn}(A)$ is a normalized max-flow upper bound between $A$ and $\bar A$: by the max-flow min-cut theorem, any single-commodity flow from $A$ to $\bar A$ cannot exceed $B_{\mathrm{res}}(A)$. Thus, if $\mathrm{Conn}(A)= 0$, region $A$ cannot support any additional external combination regardless of how the demand is routed. Second, $\mathrm{Conn}$ is monotone under embedding: because every embedding only removes bandwidth from $\delta(A)$, we have $B_{\mathrm{res}}(A;M)\le B_{\mathrm{res}}(A)$ and therefore $\mathrm{Conn}(A;M)\le\mathrm{Conn}(A)$. 
Consequently $I(A;M)-I(A)\ge0$ for every $A$, so the induced fragmentation cost is non-negative by construction. These two properties keep the metric interpretable as a resource-usability bound and ensure that the induced fragmentation cost behaves consistently under embedding.

\subsection{Node Fragmentation}
For a substrate node $v\in N^S$, we set $A=\{v\}$, so that the external connectivity of the node is given by
\[
\mathrm{Conn}_N(v)
=
\begin{cases}
\dfrac{\sum_{e\in\delta(\{v\})}r_e}
{\sum_{e\in\delta(\{v\})}c_e},
& \sum_{e\in\delta(\{v\})}c_e>0,\\[1mm]
0,
& \text{otherwise.}
\end{cases}
\]
In VNE, the residual CPU of a substrate node must combine with the bandwidth of its adjacent links to reach other substrate resources; therefore, a reduction in adjacent bandwidth lowers the future usability of that CPU. Accordingly, we define the node connectivity-deficiency factor and the node fragmentation score as
\[
I_N(v)=1-\mathrm{Conn}_N(v),
\qquad
F_N(v)=r_v I_N(v).
\]

\subsection{Link Fragmentation}
For the residual bandwidth of a substrate link $e=\{u,v\}$ to be usable for virtual-link routing, it must connect with other substrate links at both endpoints so as to form a continuous substrate path. Because the residual bandwidth of the central link $e$ itself is captured directly through $r_e$, we exclude $e$ itself when computing the external connectivity at its endpoints. That is, we define
\[
\delta(u\mid e)
=
\delta(\{u\})\setminus\{e\},
\qquad
\delta(v\mid e)
=
\delta(\{v\})\setminus\{e\}.
\]
The external connectivity at endpoint $u$ is then
\[
\mathrm{Conn}(u\mid e)
=
\begin{cases}
\dfrac{\sum_{q\in\delta(u\mid e)}r_q}
{\sum_{q\in\delta(u\mid e)}c_q},
& \sum_{q\in\delta(u\mid e)}c_q>0,\\[1mm]
0,
& \text{otherwise,}
\end{cases}
\]
and we define $\mathrm{Conn}(v\mid e)$ analogously.

For link $e$ to be used as part of a substrate path, connectivity to a subsequent link is required at both endpoints; we therefore treat the endpoint with lower external connectivity as the one that limits the usability of the link. Accordingly, we define
\[
\mathrm{Conn}_L(e)
=
\min
\left\{
\mathrm{Conn}(u\mid e),
\mathrm{Conn}(v\mid e)
\right\},
\]
and we define the link connectivity-deficiency factor and the link fragmentation score as
\[
I_L(e)=1-\mathrm{Conn}_L(e),
\qquad
F_L(e)=r_e I_L(e).
\]

We aggregate the two endpoint connectivities with a $\min$ rather than an average or a product for two reasons. Structurally, extending $e$ into a substrate path requires a further link at both endpoints, so a path can be formed only if both $\mathrm{Conn}(u\mid e)$ and $\mathrm{Conn}(v\mid e)$ remain positive; a $\min$ preserves this bottleneck semantics. Empirically, we compared $\min$, arithmetic mean, and geometric mean in a pilot run on ER $G(50,0.15)$ and observed that $\min$ produced the highest acceptance ratio, with the geometric mean second and the arithmetic mean last; the ordering matches the intuition that a link's usability is limited by its weakest endpoint. We therefore keep $\min$ as the default aggregation and treat other choices as a hyperparameter that can be revisited when both endpoints are known to carry symmetric load.

\subsection{Induced Fragmentation Cost}
The difference between the pre- and post-embedding fragmentation scores contains both the direct effect of resources being consumed and the effect of the connectivity of the remaining resources changing after that consumption. For a general fragmentation score $F=RI$, we decompose the change caused by embedding $M$ as
\[
F(M)-F
=
\bigl(R(M)-R\bigr)I
+
R(M)\bigl(I(M)-I\bigr).
\]
The first term captures the direct consumption effect from the reduction in the resource amount itself, while the second term captures the additional fragmentation effect caused by the degraded connectivity of the remaining resources after embedding. Because our objective is to measure the loss of usability of the resources that remain, we retain only the second term as induced fragmentation.

We accordingly define the induced fragmentation cost of nodes and links as
\[
\Delta F_N(M)
=
\sum_{v\in N^S}
r_v(M)
\left(
I_N(v;M)-I_N(v)
\right),
\]
\[
\Delta F_L(M)
=
\sum_{e\in L^S}
r_e(M)
\left(
I_L(e;M)-I_L(e)
\right),
\]
To make node and link induced-fragmentation costs comparable in a single scalar objective, we normalize each term by the corresponding substrate-wide capacity budget. Let $C_{N,\mathrm{tot}}=\sum_{v\in N^S}c_v$ denote the total initial CPU capacity of the substrate and $C_{L,\mathrm{tot}}=\sum_{e\in L^S}c_e$ the total initial bandwidth capacity. The normalized induced-fragmentation costs are then
\[
\widetilde{\Delta F}_N(M)=\frac{\Delta F_N(M)}{C_{N,\mathrm{tot}}},
\qquad
\widetilde{\Delta F}_L(M)=\frac{\Delta F_L(M)}{C_{L,\mathrm{tot}}},
\]
both of which are dimensionless and lie in $[0,1]$ under the monotonicity property of Section~\ref{sec:metric_definition_of_resource_fragmentation}. We define the overall induced fragmentation cost as
\[
\Delta F_{\mathrm{frag}}(M)
=
\widetilde{\Delta F}_L(M)
+
\gamma\,\widetilde{\Delta F}_N(M),
\qquad
\gamma\ge0,
\]
where $\gamma$ controls the relative weight between node and link fragmentation. Because both normalized terms share the same $[0,1]$ scale, $\gamma$ carries a clear ratio interpretation rather than absorbing the CPU-to-bandwidth unit gap.


\section{Problem Formulation}
\label{sec:problem_formulation}

The goal of \ecfvne{} is to satisfy the resource requirements of the current VNR without concentrating them on particular substrate resources, while at the same time preserving the usability of the substrate resources that remain after embedding. To this end, we compose the conventional load-balancing cost and the \ecf-based induced fragmentation cost from the previous section as independent terms and combine them into a single objective function.

The decision variable $x_{nv}\in\{0,1\}$ indicates whether virtual node $n\in N^V$ is mapped to substrate node $v\in N^S$, and $f_{uv}^l\ge0$ denotes the portion of the bandwidth demand of virtual link $l\in L^V$ that traverses arc $(u,v)\in A^S$.

\subsection{Embedding Constraints}
Each virtual node must be mapped to exactly one substrate node, and to prevent virtual nodes of the same VNR from being mapped to the same substrate node, we impose
\[
\sum_{v\in N^S}x_{nv}=1,
\qquad
\forall n\in N^V,
\]
\[
\sum_{n\in N^V}x_{nv}\le1,
\qquad
\forall v\in N^S.
\]
In addition, the total CPU demand allocated by the node mapping must not exceed the current residual CPU of each substrate node:
\[
\sum_{n\in N^V}d_nx_{nv}
\le r_v,
\qquad
\forall v\in N^S.
\]

For virtual-link routing, the sum of flows traversing a substrate link in both directions must not exceed its residual bandwidth:
\[
\sum_{l\in L^V}
\left(
f_{uv}^l+f_{vu}^l
\right)
\le r_{\{u,v\}},
\qquad
\forall\{u,v\}\in L^S.
\]
The source and destination of each virtual link $l=\{n,m\}\in L^V$ are determined by the node mapping, and we express this via the flow-conservation constraint
\[
\sum_{(v,w)\in A^S}f_{vw}^l
-
\sum_{(w,v)\in A^S}f_{wv}^l
=
d_l
\left(
x_{nv}-x_{mv}
\right),
\qquad
\forall v\in N^S.
\]
Thus, a flow of $d_l$ is generated at the substrate node with $x_{nv}=1$ and absorbed in equal amount at the substrate node with $x_{mv}=1$.

\subsection{Objective Function}
External connectivity evaluates how well a residual resource can combine with surrounding resources, but it does not directly represent the absolute residual capacity of an individual substrate resource or the load concentration on a particular resource. To complement this, we adopt the following demand-to-residual-capacity load-balancing cost ~\cite{chowdhury2012vineyard}:
\[
C_{\mathrm{LB}}(x,f)
=
\sum_{n\in N^V}
\sum_{v\in N^S}
\frac{d_n}{r_v+\epsilon}x_{nv}
+
\sum_{l\in L^V}
\sum_{(u,v)\in A^S}
\frac{f_{uv}^l}
{r_{\{u,v\}}+\epsilon},
\]
where $\epsilon>0$ is a small constant that prevents division by zero. Assigning the same demand to a resource with smaller residual capacity incurs a larger cost, thereby discouraging load concentration on heavily utilized substrate resources.

For the formulation below, we write $\Delta F_{\mathrm{frag}}(x,f)$ for the induced fragmentation cost resulting from the embedding specified by the decision variables $x$ and $f$.

We define the overall objective by combining load balancing and normalized
induced fragmentation as
\[
\min_{x,f}
\quad
J(x,f)
=
\beta\,C_{\mathrm{LB}}(x,f)
+
\lambda\,
\Delta F_{\mathrm{frag}}(x,f),
\qquad
\beta,\lambda\ge0.
\]
Here $\beta$ and $\lambda$ control the relative contributions of load
balancing and induced fragmentation, respectively, while $\gamma$ controls
the relative contribution of node fragmentation within the fragmentation
term. In this way, \ecfvne{} jointly considers load concentration for the
current request and the usability of residual substrate resources after
embedding.

\section{ECF-VNE Embedding Algorithm}
\label{sec:embedding_algorithm}

The formulation in Section~\ref{sec:problem_formulation} specifies the
objective and feasibility conditions of the proposed embedding method.
Rather than solving the formulation directly, \ecfvne{} follows the online
embedding framework of VNE-RFD~\cite{lu2022resource}. In particular, we
retain its virtual-node processing order, feasible substrate-node candidate
generation, $K$-shortest-path search, and bounded backtracking with budget
$\Delta$. The main difference is that candidate substrate nodes and paths
are evaluated using the load-balancing and induced-fragmentation terms
defined in the preceding sections.

During the embedding of an arriving VNR, $M$ represents the current partial
embedding. Whenever a node or link allocation is tentatively added to $M$,
the residual substrate state changes from $\rho$ to $\rho'$. The tentative
allocation is evaluated using

\[
\beta C_{\mathrm{LB}}
+
\lambda \Phi(\rho\rightarrow\rho'),
\]

where $C_{\mathrm{LB}}$ represents the load-balancing cost associated with
the tentative allocation and
$\Phi(\rho\rightarrow\rho')$ represents the induced fragmentation caused by
the corresponding change in the residual substrate state. Thus, candidate
selection follows the same two objectives used in $J$, without introducing
a separate evaluation metric for the heuristic.

\subsection{Path Selection}

Consider a virtual node $n$ that is tentatively mapped to a feasible
substrate node $v$. For each incident virtual link
$l=\{n,m\}$ whose neighboring virtual node $m$ has already been mapped, the
algorithm generates up to $K$ feasible shortest substrate paths between
$v$ and $M_N(m)$.

Each feasible path is temporarily assigned to $M_L(l)$ and the resulting
residual substrate state is obtained. The path is then evaluated by the
weighted combination of its load-balancing cost and the induced
fragmentation associated with the transition from $\rho$ to $\rho'$.
Among the feasible paths, the path producing the smallest value of

\[
\beta C_{\mathrm{LB}}
+
\lambda \Phi(\rho\rightarrow\rho')
\]

is retained in $M_L(l)$. The residual substrate state resulting from this
selection becomes the state used to evaluate the next incident virtual
link.

Consequently, when several virtual links become active after mapping a
virtual node, their paths are selected sequentially rather than
independently. Each routing decision therefore accounts for the resource
allocation produced by the previously selected paths.

The proposed heuristic uses unsplittable routing. Hence, each virtual link
is assigned to one substrate path among its feasible $K$-shortest paths,
while the flow variables introduced in
Section~\ref{sec:problem_formulation} remain the general representation of
link-mapping feasibility.

\subsection{Substrate-Node Selection}

For each virtual node $n$, the algorithm first obtains the feasible
substrate-node candidates according to the candidate-generation procedure
of VNE-RFD. Each candidate $v$ is then evaluated by temporarily setting
$M_N(n)=v$.

After the tentative node mapping, every incident virtual link connecting
$n$ to an already mapped virtual node is routed using the path-selection
procedure described above. If no feasible substrate path exists for any
such virtual link, the substrate-node candidate is discarded.

Otherwise, the residual substrate state obtained after the tentative node
mapping and all required link mappings is compared with the residual state
before evaluating $v$. The candidate is evaluated using the same weighted
combination

\[
\beta C_{\mathrm{LB}}
+
\lambda \Phi(\rho\rightarrow\rho'),
\]

where the load-balancing term accounts for the resources allocated by the
tentative extension of $M$, and the fragmentation term captures the loss of
usability induced in the residual substrate resources.

The feasible substrate-node candidates are considered in ascending order of
this value. Once a candidate is selected, its node and link assignments are
committed to $M$. If a later virtual node cannot be embedded, the algorithm
rolls back the previous decision and examines the next feasible candidate
according to the bounded-backtracking procedure. The VNR is rejected when
no feasible embedding can be found within the backtracking budget $\Delta$.

\begin{algorithm}[!t]
\caption{ECF-VNE Online Embedding}
\label{alg:ecf_embedding}
\footnotesize
\begin{algorithmic}[1]

\STATE \textbf{Input:} $G^S$, $G^V$, $K$, $\Delta$
\STATE \textbf{Output:} embedding $M$ or \textsc{Reject}
\STATE Initialize $M$

\FOR{each $n\in N^V$ according to the VNE-RFD processing order}

    \STATE Generate feasible substrate-node candidates

    \FOR{each candidate $v$}
        \STATE Tentatively set $M_N(n)\leftarrow v$
        \STATE Route newly activated virtual links using up to $K$ feasible paths
        \STATE Evaluate the tentative embedding using
        $\beta C_{\mathrm{LB}}+\lambda\Phi(\rho\rightarrow\rho')$
        \STATE Restore $M$
    \ENDFOR

    \STATE Rank feasible candidates by the evaluated value

    \STATE Commit the best feasible candidate and its link mappings

    \IF{no candidate leads to a feasible continuation}
        \STATE Backtrack to the next candidate according to $\Delta$
    \ENDIF

\ENDFOR

\IF{a complete embedding is found}
    \STATE return $M$
\ELSE
    \STATE return \textsc{Reject}
\ENDIF

\end{algorithmic}
\end{algorithm}


\section{Performance Evaluation}
\label{sec:performance_evaluation}

\subsection{실험 설정 및 평가 지표}
제안하는 \ecfvne{}의 online embedding 성능은 VNE-RFD-B, VNE-RFD-D, D-ViNE, R-ViNE와 비교한다. Substrate node의 CPU capacity와 substrate link의 bandwidth capacity는 각각 $U(50,100)$에서 생성한다. 각 VNR은 2--10개의 virtual node를 갖는 connected Erd\H{o}s--R\'{e}nyi graph $G(n,0.4)$로 생성하고, virtual node의 CPU demand는 $U(0,20)$, virtual link의 bandwidth demand는 $U(0,50)$에서 생성한다.

VNR은 Poisson process에 따라 도착하며, holding time은 평균 1,000 time units의 exponential distribution을 따른다. 각 simulation은 초기 과도 상태를 제거한 뒤 steady-state 구간에서 50,000 time units 동안 성능 지표를 집계한다. 주요 평가지표는 VNR acceptance ratio, revenue-to-cost ratio, average CPU utilization, average link utilization이다. \subsection{실제 Topology Zoo Network에서의 성능}
Synthetic ER graph에서 관찰한 결과가 특정 random topology에 한정되지 않는지 확인하기 위해 Internet Topology Zoo의 실제 network topology를 substrate로 사용한다. 원본 topology에 포함된 parallel edge는 병합하여 simple graph로 변환하고, 규모가 유사한 Palmetto $(45,64)$, Bell Canada $(48,64)$, Surfnet $(50,68)$을 선택한다. 괄호 안의 값은 각각 node 수와 link 수를 의미한다. 세 topology의 규모를 유사하게 유지함으로써 network size 차이의 영향을 줄이고, 서로 다른 실제 연결 구조에 대한 \ecfvne{}의 robustness를 평가한다.

Substrate resource와 VNR generation, holding time, simulation duration, paired sampling 조건은 ER 실험과 동일하게 설정한다. 대신 VNR arrival rate를 1,000 time units당 5, 10, 15, 20, 25개로 변화시켜 workload 증가에 따른 성능 변화를 비교한다.

Fig.~\ref{fig:zoo_arrival_rate}에서 세 topology 모두 arrival rate가 증가할수록 resource contention이 커지면서 acceptance ratio가 감소한다. 그러나 \ecfvne{}는 모든 topology와 arrival-rate 조건에서 가장 높은 acceptance ratio를 유지한다. 이는 ER substrate의 $p_s$-sweep에서 나타난 수용률 향상이 실제 network structure에서도 일관되게 재현됨을 보여주며, external-connectivity 기반 fragmentation 제어가 특정 random topology에만 의존하지 않음을 뒷받침한다.

Revenue-to-cost ratio에서는 VNE-RFD-B와 VNE-RFD-D가 일부 조건에서 더 높은 비용 효율을 보이지만, \ecfvne{}는 그보다 많은 VNR을 수용하면서 높은 CPU utilization을 보인다. Link utilization은 topology와 workload에 따라 서로 다른 양상을 보일 수 있으나, 세 실제 topology에서 \ecfvne{}의 상대적인 acceptance-ratio 우위가 유지된다는 점은 제안한 residual-resource usability 관점이 다양한 substrate 구조에서도 유효함을 보여준다.


\section{Conclusion}
\label{sec:conclusion}

본 논문에서는 online VNE에서 반복적인 임베딩으로 인해 잔여 자원의 총량이 충분하더라도 다른 잔여 자원과 효과적으로 결합되지 못해 향후 요청에 활용하기 어려워지는 resource fragmentation 문제를 다루었다. 이를 위해 잔여 자원의 양뿐 아니라 주변 자원과의 결합 가능성을 external connectivity로 나타내고, 이를 기반으로 잔여 자원의 활용 가능성을 정량화하는 \ecf{} metric을 제안하였다. 또한 node embedding과 link routing에서 요구되는 자원 결합 방식의 차이를 반영하여 node와 link에 대한 fragmentation score를 각각 정의하였다.

임베딩 전후의 fragmentation score 변화에서는 자원 자체가 소비된 효과와 남아 있는 자원의 connectivity가 저하된 효과를 분리하고, 후자를 induced fragmentation cost로 정의하였다. \ecfvne{}는 이 비용을 load-balancing cost와 함께 고려함으로써 현재 VNR의 feasibility와 resource usage뿐 아니라 임베딩 이후 남게 되는 substrate resource의 활용 가능성을 embedding decision에 반영한다.

Erd\H{o}s--R\'{e}nyi substrate의 edge probability를 변화시킨 실험과 Internet Topology Zoo의 실제 network structure를 이용한 실험에서, \ecfvne{}는 서로 다른 substrate connectivity와 VNR arrival-rate 조건에서도 비교 알고리즘보다 높은 VNR acceptance ratio를 일관되게 나타냈다. 일부 조건에서는 개별 embedding의 revenue-to-cost ratio가 VNE-RFD 계열보다 낮게 나타났지만, 더 많은 VNR을 지속적으로 수용하면서 substrate resource를 활용한다는 점에서 제안한 fragmentation-aware embedding의 목적과 일관된 결과를 보였다.

한편 제안 지표는 각 substrate node 또는 link 주변의 local external connectivity를 이용하여 잔여 자원의 결합 가능성을 평가하므로, 외부로 연결되는 여러 경로 사이의 resource-sharing 관계까지 직접 포착하지는 않는다. 서로 다른 boundary link가 이후 동일한 substrate link 또는 bottleneck 구간을 공유하는 경우, 각 지역에서 관찰되는 external connectivity가 높더라도 실제 독립적인 embedding capacity는 제한될 수 있다. 따라서 현재 지표는 residual resource의 local usability를 효율적으로 평가하지만, substrate 전역의 path overlap 또는 shared bottleneck에 의해 발생하는 상호 의존성을 완전히 표현하지는 않는다.

향후 연구에서는 external connectivity를 path overlap, shared bottleneck, 또는 더 넓은 범위의 flow 및 cut structure와 결합하여 이러한 한계를 보완할 수 있다. 특히 online VNE에서 반복적으로 평가할 수 있는 계산 복잡도를 유지하면서 local resource connectivity와 global resource-sharing 관계를 동시에 반영하는 fragmentation metric을 설계하는 것이 중요한 연구 과제가 될 수 있다.
