\section{Introduction}
\label{sec:introduction}

% VNE 의 배경과 정의
Modern network infrastructures must serve diverse tenants and applications simultaneously. These services range from latency sensitive real time traffic to bandwidth intensive data transfers, and their resource requirements are often heterogeneous. Network virtualization addresses these requirements by abstracting physical infrastructure into virtual resources. Each service request is commonly modeled as a virtual network request (VNR) with node and link resource requirements. Mapping a VNR onto the substrate network requires node mapping and virtual link routing, a process known as virtual network embedding (VNE)~\cite{satpathy2025virtual}.

% Dynamic VNE 의 어려움 + 파편화 문제로 인한 미래 자원 활용성
In practical deployments, VNE operates in a dynamic setting where VNRs arrive and depart over time. Each embedding decision must therefore be made online under changing substrate resource availability. This setting is challenging for two reasons. First, VNE is computationally intractable: the decision version is NP-complete, and optimization variants are NP-hard~\cite{rost2020hardness}. Practical algorithms therefore rely on heuristic strategies rather than globally optimal solutions. Second, each locally feasible decision changes the residual substrate state available to future requests. As VNRs are repeatedly embedded and released, residual resources may become distributed in ways that make future embeddings difficult, even when sufficient aggregate capacity remains. This degradation of future resource usability is commonly referred to as resource fragmentation~\cite{fischer2013virtual}. A locally feasible embedding may therefore serve the current request while increasing the likelihood that later requests are rejected.

% 기존 방법의 한계
Existing online VNE heuristics manage residual capacity, path feasibility, and embedding cost during node and link mapping. However, their control granularity is mainly limited to individual substrate nodes, adjacent link sets, candidate paths, or aggregate load balancing objectives. These approaches do not explicitly quantify resource fragmentation in the residual substrate state.

\section{Relate Work}
\label{sec:related_work}

\subsection{Resource Aware and Topology Aware VNE}

Conventional VNE heuristics commonly prioritize candidate substrate nodes by residual CPU, residual bandwidth, node degree, centrality, or combinations of these quantities. Ranking methods inspired by PageRank and node ranking heuristics driven by resource information compute the topological importance of substrate nodes. These methods then map virtual links through shortest paths or $k$ shortest paths~\cite{cao2017novel,hashmi2020vne}. Other studies use betweenness centrality, closeness centrality, degree, strength, and multiple topology attributes to guide node mapping~\cite{ding2015virtual,guler2016closeness,feng2014topology}. Recent methods with multiple criteria refine this node level ranking approach. NORD combines weighting based on entropy with TOPSIS to compute node ranks from resource and topology attributes~\cite{tg2023nord}. Simplified ELECTRE integrates multiple node metrics and constraints when evaluating candidate substrate nodes~\cite{zhang2018virtual}. These methods treat connectivity as a static, local attribute of individual substrate nodes. Such ranking methods do not evaluate how each embedding decision alters connectivity among residual substrate resource sets.
% 

Several studies coordinate node mapping and link mapping in a tighter manner. Because link mapping may fail after an independently chosen node mapping, coordinated approaches solve the two phases in a single stage or in a coupled two stage procedure~\cite{chowdhury2012vineyard,lu2023performance,nguyen2022toward}. Related heuristics also consider congestion, energy consumption, latency, or path structure when selecting embeddings~\cite{pham2019congestion,zheng2017link,yan2019latency}. These methods jointly consider node mapping and link routing. However, their objectives focus on path level feasibility and cost rather than on connectivity degradation after routing. Load balancing approaches discourage excessive concentration on particular substrate nodes or links and aim to maintain balanced utilization over the substrate network~\cite{gong2014toward,shanbhag2015vhub,li2022load}. These objectives treat substrate nodes primarily as interchangeable units of capacity. Load balancing objectives do not account for the structural positions of nodes and links that maintain connectivity across the residual substrate network.

\subsection{Survivable VNE Under Substrate Failures}

Survivable VNE aims to keep virtual network services available after substrate failures. Prior work reserves backup paths or redundant node and link resources, constructs backup topologies, or remaps affected virtual components after failures~\cite{liao2014survivable,chowdhury2016dedicated,liu2017scheme,zheng2019heuristic,sun2011framework,zhu2014heuristic}. Within this line, Shahriar et al.~\cite{shahriar2019virtual} are most relevant to this study because CoViNE explicitly formulates VN connectivity guarantees under multiple substrate link failures. Their formulation separates connectivity from broader survivability requirements such as full bandwidth protection. This paper uses a similar separation for fragmentation. Node and link capacities define feasible embeddings, while the objective isolates how each feasible embedding changes residual connectivity among substrate resource sets. The difference is the operating regime. CoViNE protects an already embedded VN against discrete substrate failures. In contrast, this paper addresses how online embeddings without failures gradually degrade the connectivity among residual substrate resource sets.

\subsection{Fragmentation Aware VNE}

Fragmentation aware VNE directly addresses the residual resource fragmentation caused by repeated arrivals and departures of VNRs. These studies modify the embedding objective so that residual substrate resources remain useful for future requests, rather than merely abundant in aggregate. Guan et al.~\cite{guan2023multidimensional} study multidimensional resource fragmentation in VNE oriented to multiaccess edge computing (MEC). Their method penalizes resource imbalance across computing, wireless, and optical spectrum resources. The resulting metric captures multidimensional resource imbalance, but not the structural connectivity of residual substrate resources. Lu and Zhang~\cite{lu2022resource} address the most similar concern. The RFD metrics use paths with hop limits and adjacent link information to penalize embeddings that leave residual substrate resources difficult to reuse. This path level view is related to bottleneck and cut intuitions. However, averaging path level scores does not directly model residual connectivity loss after a candidate embedding changes the residual substrate state.

To the best of our knowledge, existing VNE fragmentation metrics have not directly modeled residual connectivity loss as an online embedding objective. In contrast, the proposed metric complements node and link feasibility constraints with a signal based on residual connectivity among substrate node sets.
