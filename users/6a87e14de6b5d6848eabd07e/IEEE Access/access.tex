\begin{abstract}
Online virtual network embedding must accommodate arriving requests while preserving residual substrate resources for future demands.
\todobox{초록에 추가할 내용}{
    \item Online VNE에서는 현재 VNR을 수용하는 것뿐 아니라 이후 도착하는 요청을 위해 잔여 substrate resource의 활용 가능성을 보존하는 것이 중요하다. 기존 방법들은 잔여 자원의 절대량이나 부하 분산을 주로 고려하지만, 남은 자원이 향후 VNR을 구성하는 다른 자원과 실제로 결합될 수 있는 정도는 직접 정량화하지 않는다.

    \item 본 논문에서는 이러한 잔여 자원의 결합 가능성을 external connectivity로 정량화하는 \ecfvne{}를 제안한다. \ecfvne{}는 잔여 자원량과 normalized external connectivity를 결합한 External-Connectivity-based Fragmentation (\ecf) metric을 사용하고, node embedding과 link routing이 요구하는 서로 다른 자원 결합 관계에 맞게 node와 link fragmentation을 정의한다.

    \item 또한 임베딩 전후의 fragmentation 변화에서 자원 자체가 소비되는 효과와 남은 자원의 connectivity가 저하되는 효과를 분리하고, 후자만을 induced fragmentation cost로 반영한다. 이를 load-balancing cost와 함께 node candidate 및 path selection에 적용하여 현재 요청의 실행 가능성과 향후 잔여 자원의 활용 가능성을 동시에 고려한다.

    \item 실험 결과, \ecfvne{}는 synthetic ER substrate의 연결 밀도와 실제 Topology Zoo network의 workload가 변하는 조건에서도 비교 기법보다 높은 VNR acceptance ratio를 일관되게 보였다. 일부 조건에서 revenue-to-cost ratio의 trade-off가 존재하지만, 더 많은 VNR을 수용하면서 substrate resource를 지속적으로 활용한다는 점에서 online embedding의 장기적 수용 성능을 개선하였다.
}

\end{abstract}

\section{Introduction}
\label{sec:introduction}

% VNE 의 배경과 정의
Modern network infrastructures must serve diverse tenants and applications simultaneously. These services range from latency sensitive real time traffic to bandwidth intensive data transfers, and their resource requirements are often heterogeneous. Network virtualization addresses these requirements by abstracting physical infrastructure into virtual resources. Each service request is commonly modeled as a virtual network request (VNR) with node and link resource requirements. Mapping a VNR onto the substrate network requires node embedding and virtual link routing, a process known as virtual network embedding (VNE)~\cite{satpathy2025virtual}.

% Dynamic VNE 의 어려움 + 파편화 문제로 인한 미래 자원 활용성
In practical deployments, VNE operates in a dynamic setting where VNRs arrive and depart over time. Each embedding decision must therefore be made online under changing substrate resource availability. This setting is challenging for two reasons. First, VNE is computationally intractable: the decision version is NP-complete, and optimization variants are NP-hard~\cite{rost2020hardness}. Practical algorithms therefore rely on heuristic strategies rather than globally optimal solutions. Second, each locally feasible decision changes the residual substrate state available to future requests. As VNRs are repeatedly embedded and released, residual resources may become distributed in ways that make future embeddings difficult, even when sufficient aggregate capacity remains. This degradation of future resource usability is commonly referred to as resource fragmentation~\cite{fischer2013virtual}. A locally feasible embedding may therefore serve the current request while increasing the likelihood that later requests are rejected.

% 기존 방법의 한계
Existing online VNE heuristics manage residual capacity, path feasibility, and embedding cost during node and link routing. However, their control granularity is mainly limited to individual substrate nodes, adjacent link sets, candidate paths, or aggregate load balancing objectives. These approaches do not explicitly quantify resource fragmentation in the residual substrate state.

VNE에서 잔여 자원의 가치는 단순히 남아 있는 CPU 또는 bandwidth의 절대량만으로 결정되지 않는다. VNR은 node와 link가 결합된 그래프 구조이므로, 특정 substrate resource에 충분한 잔여 용량이 존재하더라도 주변 자원과 함께 향후 요청을 구성하기 어렵다면 그 자원의 실질적인 활용 가능성은 낮다. 따라서 online VNE에서는 현재 요청의 feasibility뿐 아니라 임베딩 이후 남는 자원이 다른 잔여 자원과 얼마나 효과적으로 결합될 수 있는지를 함께 고려할 필요가 있다.

본 논문에서는 이러한 관점에서 external connectivity를 이용해 잔여 자원의 결합 가능성을 평가하는 \ecfvne{}를 제안한다. \ecfvne{}는 잔여 자원량과 외부 자원으로 연결될 수 있는 정도를 함께 고려하여, 자원이 물리적으로 남아 있음에도 다른 자원과 결합되기 어려운 상태를 fragmentation으로 정량화한다. 이를 위해 잔여 자원량과 normalized external connectivity를 결합한 External-Connectivity-based Fragmentation (\ecf) metric을 정의한다.

Node embedding과 link routing은 서로 다른 형태의 자원 결합을 요구한다. Substrate node의 CPU는 인접 substrate link의 bandwidth를 통해 다른 자원과 연결되어야 하며, substrate link의 bandwidth는 양 끝점에서 다른 link와 연속적으로 연결되어 substrate path를 구성할 수 있어야 한다. 따라서 본 논문은 동일한 external-connectivity 관점을 유지하면서도, node와 link가 VNE에서 수행하는 역할에 맞추어 fragmentation을 각각 정의한다.

또한 임베딩 전후의 fragmentation score 변화에는 직접적인 자원 소비와 잔여 자원의 connectivity 저하가 동시에 포함된다. 본 논문은 두 효과를 분리하고, 자원 소비 이후 남은 자원의 connectivity 저하로 인해 발생하는 부분만을 induced fragmentation cost로 정의한다. \ecfvne{}는 이 비용을 기존의 load-balancing cost와 함께 node candidate 및 path selection에 반영함으로써 현재 VNR을 수용하는 동시에 이후 요청에 사용할 수 있는 substrate resource의 활용 가능성을 보존한다.

이와 같은 관점에서 본 논문의 주요 기여는 다음과 같이 요약할 수 있다. 잔여 자원의 절대량이 아니라 다른 자원과의 결합 가능성을 중심으로 resource fragmentation을 정의하고, external connectivity에 기반한 통일된 \ecf{} metric을 node와 link에 각각 특수화한다. 또한 induced fragmentation을 직접적인 자원 소비 효과와 분리하여 online VNE의 node 및 path selection에 반영하는 \ecfvne{}를 제안한다.

\section{Related Work}
\label{sec:related_work}

\subsection{Resource- and Topology-Aware VNE}

Conventional VNE heuristics commonly prioritize candidate substrate nodes according to residual CPU, residual bandwidth, node degree, centrality, or combinations of these quantities. PageRank-inspired and other resource-aware node-ranking heuristics use resource and topology information to estimate the suitability of substrate nodes, followed by virtual link routing through shortest paths or $k$ shortest paths~\cite{cao2017novel,hashmi2020vne}. Other studies use betweenness centrality, closeness centrality, degree, strength, and multiple topology attributes to guide node embedding~\cite{ding2015virtual,guler2016closeness,feng2014topology}. More recent multi-criteria methods further combine several node attributes into a single ranking score. NORD combines entropy-based weighting with TOPSIS to rank substrate nodes~\cite{tg2023nord}, while simplified ELECTRE evaluates candidate substrate nodes using multiple node metrics and constraints~\cite{zhang2018virtual}. These approaches primarily use resource and topology information to estimate candidate-node suitability for the current embedding decision rather than to characterize fragmentation of the residual substrate state.

Another line of work coordinates node embedding and link routing because independently selected node embeddings can lead to infeasible or costly link routings. Coordinated approaches therefore solve the two mapping operations jointly or through coupled stages~\cite{chowdhury2012vineyard,lu2023performance,nguyen2022toward}. Related methods extend this consideration by incorporating congestion, energy consumption, latency, or path characteristics into embedding decisions~\cite{pham2019congestion,zheng2017link,yan2019latency}. Such coordination determines how node and link allocation decisions interact and can improve the feasibility or cost of an embedding. However, coordination and resource fragmentation address different aspects of VNE: coordination determines how an embedding is constructed, whereas fragmentation metrics characterize the usability of the residual resources left by that embedding.

Load-balancing approaches address another related aspect by discouraging excessive resource concentration on particular substrate nodes or links~\cite{gong2014toward,shanbhag2015vhub,li2022load}. Some load-balancing methods additionally use global resource information or neighboring bandwidth when evaluating node-embedding potential. These objectives seek a balanced distribution of substrate utilization. Resource balance and resource fragmentation, however, are not equivalent. From the fragmentation perspective adopted in this paper, the relevant question is whether a residual resource can still be used together with the other resources required by a future mapping operation, rather than only whether residual resources are evenly distributed across the substrate network. This distinction does not exclude load balancing; instead, this paper retains load balancing separately through the resource-usage term $C_{\mathrm{use}}$, while modeling fragmentation cost as a distinct objective.

\subsection{Survivable VNE Under Substrate Failures}

Survivable VNE addresses service availability under substrate failures. Prior studies reserve backup paths or redundant node and link resources, construct backup topologies, or remap affected virtual components after failures~\cite{liao2014survivable,chowdhury2016dedicated,liu2017scheme,zheng2019heuristic,sun2011framework,zhu2014heuristic}. Shahriar et al.~\cite{shahriar2019virtual} formulate Connectivity-aware Virtual Network Embedding (CoViNE), which guarantees VN connectivity under multiple substrate link failures without requiring full bandwidth protection. CoViNE uses VN augmentation and disjointness requirements to preserve connectivity after failures. Survivable VNE concerns whether an embedded VN can continue to satisfy a survivability requirement after substrate failures, whereas this paper considers the usability of residual resources resulting from online embedding decisions under normal operation.

\subsection{Fragmentation-Aware VNE}

The following studies are most closely related to the fragmentation notion considered in this paper. Fragmentation-aware VNE explicitly considers residual resources that become difficult to use despite remaining available. 

Guan et al.~\cite{guan2023multidimensional} study multidimensional resource fragmentation for VNE in MEC systems interconnected by optical networks. For physical nodes, their formulation characterizes fragmentation through imbalanced utilization of computing and wireless resources. For physical links, it identifies unusable or difficult-to-use optical spectrum fragments created under spectrum continuity and consistency constraints. Their bilevel formulation also accounts for the dependency between virtual node embedding and virtual link routing. Thus, their fragmentation model focuses on imbalance among heterogeneous node resources and contiguity of optical spectrum resources, which differs from the CPU--bandwidth resource relationships addressed in this paper. Whereas this paper treats node and link fragmentation as two instances of the same general form $F=R(1-\mathrm{Conn})$, Guan et al. formulate two problems with different characteristics: node imbalance and link spectrum continuity.

Lu and Zhang~\cite{lu2022resource} address a more closely related notion of resource fragmentation. They define the resource fragmentation degree (RFD) for substrate nodes and links based on the observation that the usability of a residual resource depends on surrounding residual resources. For a substrate node, RFD incorporates residual resources of neighboring nodes and paths within a bounded hop count. For a substrate link, RFD incorporates the residual resources of adjacent links and the substrate nodes shared by those links. Their formulation is motivated by an extension of graph connectivity and aggregates these surrounding resource states to quantify the fragmentation degree of each substrate element. This connectivity extension depends on a hop-bounded neighborhood and its associated hyperparameter, whereas the external connectivity used in this paper is justified directly by the boundary cut, equivalently the max-flow between a resource region and its exterior, and requires no hop-count tuning.

The proposed metric shares with RFD the observation that residual resource amount alone is insufficient to characterize future usability. The distinction lies in how the relevant resource relationships are modeled. Rather than deriving a connectivity-inspired fragmentation degree from surrounding nodes and paths, the proposed metric directly follows the resource combinations required by the two VNE mapping operations. For node embedding, it evaluates the residual resource of a substrate node together with the residual resources of its adjacent substrate links, because both are required to support a virtual node and its incident virtual links. For link routing, it evaluates the residual resource of a substrate link together with the adjacent link resources at each of its two endpoints. The two endpoint states are evaluated separately, and the endpoint with lower adjacent-resource availability determines the resulting value because insufficient adjacent resources at either endpoint can limit the use of the substrate link as part of a path.

Accordingly, the proposed metric differs from the reviewed fragmentation metrics not in whether neighboring resources are considered, but in how their relationships are defined. It characterizes residual-resource usability according to the distinct resource combinations required by node embedding and link routing, aiming to identify residual resources that remain available but are difficult to combine with other resources in future VNR embeddings. In addition, the formulation distinguishes the direct resource-consumption effect of an embedding from the connectivity degradation it induces, with the latter represented through the external connectivity metric introduced in the next section.

Substrate network는 weighted undirected graph $G^S=(N^S,L^S)$로 정의한다. 여기서 $N^S$와 $L^S$는 각각 substrate node와 substrate link의 집합이다. Substrate node $v\in N^S$의 초기 CPU 용량과 현재 잔여 CPU 용량을 각각 $c_v$와 $r_v$로 두며, substrate link $e=\{u,v\}\in L^S$의 초기 bandwidth 용량과 현재 잔여 bandwidth 용량을 각각 $c_e$와 $r_e$로 정의한다. Virtual-link routing의 경로와 flow를 표현하기 위해 각 무방향 substrate link $\{u,v\}\in L^S$를 두 방향 arc $(u,v)$와 $(v,u)$로 확장하고, 이들의 집합을 $A^S$로 둔다.

하나의 VNR은 weighted undirected graph $G^V=(N^V,L^V)$로 표현한다. $N^V$와 $L^V$는 각각 virtual node와 virtual link의 집합이며, virtual node $n\in N^V$의 CPU 요구량을 $d_n$, virtual link $l=\{n,m\}\in L^V$의 bandwidth 요구량을 $d_l$로 정의한다.

Node mapping은 $M_N:N^V\rightarrow N^S$로 정의한다. 각 virtual node는 정확히 하나의 substrate node에 매핑되며, 동일한 VNR에 속한 서로 다른 virtual node는 서로 다른 substrate node에 매핑되는 것을 가정한다. Binary variable $x_{nv}\in\{0,1\}$를 사용하며, $x_{nv}=1$이면 virtual node $n$이 substrate node $v$에 매핑되었음을 의미한다. Link mapping은 $M_L:L^V\rightarrow\mathcal{P}^S$로 정의하며, virtual link $l=\{n,m\}$은 $M_N(n)$과 $M_N(m)$을 연결하는 substrate path에 매핑된다. 이때 $f_{uv}^l\ge0$는 arc $(u,v)\in A^S$를 통과하는 virtual link $l$의 bandwidth flow를 나타낸다.

전체 VNR embedding을 $M=(M_N,M_L)$로 정의한다. 임베딩 $M$을 적용한 이후 substrate node와 substrate link의 잔여 자원은 각각 다음과 같이 갱신된다.
\[
r_v(M)
=
r_v-\sum_{n\in N^V}d_nx_{nv},
\qquad \forall v\in N^S,
\]
\[
r_{\{u,v\}}(M)
=
r_{\{u,v\}}
-
\sum_{l\in L^V}
\left(
f_{uv}^l+f_{vu}^l
\right),
\qquad
\forall\{u,v\}\in L^S.
\]
이와 같이 정의된 임베딩 전후의 residual substrate state는 이후 \ecf{} metric과 induced fragmentation cost를 계산하는 기준이 된다.



\section{External-Connectivity-Based Fragmentation Metric}
\label{sec:metric_definition_of_resource_fragmentation}

본 논문에서는 잔여 자원량과 external connectivity를 결합하여 잔여 자원의 향후 활용 가능성을 나타내는 External-Connectivity-based Fragmentation (\ecf) metric을 정의한다. \ecf{}는 node와 link에 공통된 기본 형태를 사용하되, 두 자원이 VNE에서 다른 자원과 결합되는 방식의 차이를 각각 반영한다.

\subsection{기본 정의와 External Connectivity}
VNE에서 잔여 자원의 활용 가능성은 해당 자원의 양뿐 아니라 주변 자원과의 결합 가능성에 의해 결정된다. 잔여 자원량을 $R$, normalized external connectivity를 $\mathrm{Conn}$이라 할 때, 외부 자원과 결합하여 실제로 활용할 수 있는 잔여 자원을 $R\mathrm{Conn}$으로 본다. 이에 따라 fragmentation score를 다음과 같이 정의한다.
\[
F=R(1-\mathrm{Conn}).
\]
$\mathrm{Conn}$이 1에 가까울수록 잔여 자원이 외부 자원과 충분히 결합될 수 있으므로 fragmentation은 작아지고, 반대로 external connectivity가 감소할수록 동일한 잔여 자원량이라도 fragmentation score는 증가한다.

External connectivity를 구체적으로 정의하기 위해 $\emptyset\neq A\subsetneq N^S$와 $\bar A=N^S\setminus A$를 고려한다. 영역 $A$와 외부 영역 $\bar A$를 연결하는 boundary link set은
\[
\delta(A)
=
\{\,e=\{u,v\}\in L^S
\mid
u\in A,\ v\in\bar A\,\}
\]
로 정의한다. 이 boundary의 초기 및 현재 bandwidth capacity는 각각
\[
B_{\mathrm{cap}}(A)
=
\sum_{e\in\delta(A)}c_e,
\qquad
B_{\mathrm{res}}(A)
=
\sum_{e\in\delta(A)}r_e
\]
이며, normalized external connectivity는
\[
\mathrm{Conn}(A)
=
\begin{cases}
\dfrac{B_{\mathrm{res}}(A)}{B_{\mathrm{cap}}(A)},
& B_{\mathrm{cap}}(A)>0,\\[1mm]
0,
& B_{\mathrm{cap}}(A)=0
\end{cases}
\]
로 정의한다. $A$와 $\bar A$를 각각 super source와 super sink에 연결하면 두 영역을 분리하는 cut은 $\delta(A)$가 되므로, boundary capacity는 영역 $A$가 외부와 연결될 수 있는 용량을 나타낸다.

\subsection{Node Fragmentation}
Substrate node $v\in N^S$에 대해 $A=\{v\}$로 두면 node의 external connectivity는
\[
\mathrm{Conn}_N(v)
=
\begin{cases}
\dfrac{\sum_{e\in\delta(\{v\})}r_e}
{\sum_{e\in\delta(\{v\})}c_e},
& \sum_{e\in\delta(\{v\})}c_e>0,\\[1mm]
0,
& \text{otherwise}
\end{cases}
\]
로 주어진다. VNE에서 substrate node의 잔여 CPU는 인접 link의 bandwidth를 통해 다른 substrate resource와 결합되어야 하므로, 인접 bandwidth의 감소는 해당 CPU의 향후 활용 가능성을 낮춘다. 따라서 node connectivity-deficiency factor와 node fragmentation score를 각각
\[
I_N(v)=1-\mathrm{Conn}_N(v),
\qquad
F_N(v)=r_v I_N(v)
\]
로 정의한다.

\subsection{Link Fragmentation}
Substrate link $e=\{u,v\}$의 잔여 bandwidth가 virtual-link routing에 활용되기 위해서는 양 끝점에서 다른 substrate link와 연결되어 연속적인 substrate path를 구성할 수 있어야 한다. 중심 link $e$의 잔여 bandwidth는 $r_e$를 통해 직접 반영되므로, 끝점의 external connectivity를 계산할 때에는 $e$ 자체를 제외한다. 즉,
\[
\delta(u\mid e)
=
\delta(\{u\})\setminus\{e\},
\qquad
\delta(v\mid e)
=
\delta(\{v\})\setminus\{e\}
\]
로 정의한다. 끝점 $u$에서의 external connectivity는
\[
\mathrm{Conn}(u\mid e)
=
\begin{cases}
\dfrac{\sum_{q\in\delta(u\mid e)}r_q}
{\sum_{q\in\delta(u\mid e)}c_q},
& \sum_{q\in\delta(u\mid e)}c_q>0,\\[1mm]
0,
& \text{otherwise}
\end{cases}
\]
이며, $\mathrm{Conn}(v\mid e)$도 동일하게 정의한다.

Link $e$가 substrate path의 일부로 사용되려면 양 끝점 모두에서 후속 link와의 연결 가능성이 필요하므로, 두 끝점 중 external connectivity가 낮은 쪽이 해당 link의 활용 가능성을 제한한다고 본다. 이에 따라
\[
\mathrm{Conn}_L(e)
=
\min
\left\{
\mathrm{Conn}(u\mid e),
\mathrm{Conn}(v\mid e)
\right\}
\]
로 정의하고, link connectivity-deficiency factor와 link fragmentation score를
\[
I_L(e)=1-\mathrm{Conn}_L(e),
\qquad
F_L(e)=r_e I_L(e)
\]
로 정의한다.

\subsection{Induced Fragmentation Cost}
임베딩 전후의 fragmentation score 차이에는 자원 자체가 소비된 효과와, 자원 소비 이후 남은 자원의 connectivity가 변한 효과가 함께 포함된다. 일반적인 fragmentation score $F=RI$에 대해 임베딩 $M$ 적용 전후의 차이는
\[
F(M)-F
=
\bigl(R(M)-R\bigr)I
+
R(M)\bigl(I(M)-I\bigr)
\]
로 분해할 수 있다. 첫 번째 항은 임베딩으로 인해 자원량 자체가 감소한 직접적인 consumption effect이고, 두 번째 항은 임베딩 이후 남은 자원의 connectivity가 저하되어 추가로 발생한 fragmentation effect이다. 본 논문의 목적은 남아 있는 자원의 활용 가능성 저하를 측정하는 것이므로 induced fragmentation에는 두 번째 항만을 반영한다.

이에 따라 node와 link의 induced fragmentation cost를 각각
\[
\Delta F_N(M)
=
\sum_{v\in N^S}
r_v(M)
\left(
I_N(v;M)-I_N(v)
\right),
\]
\[
\Delta F_L(M)
=
\sum_{e\in L^S}
r_e(M)
\left(
I_L(e;M)-I_L(e)
\right)
\]
로 정의한다. 최종적으로 전체 induced fragmentation cost는
\[
\Delta F_{\mathrm{frag}}(M)
=
\Delta F_L(M)
+
\gamma\Delta F_N(M),
\qquad
\gamma\ge0
\]
로 정의하며, $\gamma$는 node fragmentation과 link fragmentation 사이의 상대적 가중치를 조절한다.



\section{Problem Formulation}
\label{sec:problem_formulation}

\ecfvne{}는 현재 VNR의 자원 요구를 특정 substrate resource에 과도하게 집중시키지 않으면서, 임베딩 이후 남는 substrate resource의 활용 가능성을 함께 보존하는 것을 목표로 한다. 이를 위해 기존의 load-balancing cost와 앞 절에서 정의한 \ecf{} 기반 induced fragmentation cost를 독립적인 항으로 구성한 뒤 하나의 목적함수에서 결합한다.

결정변수 $x_{nv}\in\{0,1\}$는 virtual node $n\in N^V$가 substrate node $v\in N^S$에 매핑되는지를 나타내며, $f_{uv}^l\ge0$는 virtual link $l\in L^V$의 bandwidth 중 arc $(u,v)\in A^S$를 통과하는 flow를 나타낸다.

\subsection{Embedding Constraints}
각 virtual node는 정확히 하나의 substrate node에 매핑되어야 하며, 동일한 VNR의 virtual node가 하나의 substrate node에 중복 매핑되지 않도록 다음 제약을 둔다.
\[
\sum_{v\in N^S}x_{nv}=1,
\qquad
\forall n\in N^V,
\]
\[
\sum_{n\in N^V}x_{nv}\le1,
\qquad
\forall v\in N^S.
\]
또한 node mapping으로 할당되는 CPU demand의 합은 각 substrate node의 현재 잔여 CPU를 초과할 수 없다.
\[
\sum_{n\in N^V}d_nx_{nv}
\le r_v,
\qquad
\forall v\in N^S.
\]

Virtual-link routing에 대해서는 하나의 substrate link를 양방향으로 통과하는 모든 flow의 합이 해당 link의 잔여 bandwidth를 초과하지 않도록 한다.
\[
\sum_{l\in L^V}
\left(
f_{uv}^l+f_{vu}^l
\right)
\le r_{\{u,v\}},
\qquad
\forall\{u,v\}\in L^S.
\]
Virtual link $l=\{n,m\}\in L^V$의 source와 destination은 node mapping 결과에 의해 결정되며, 이를 위해 다음 flow-conservation constraint를 사용한다.
\[
\sum_{(v,w)\in A^S}f_{vw}^l
-
\sum_{(w,v)\in A^S}f_{wv}^l
=
d_l
\left(
x_{nv}-x_{mv}
\right),
\qquad
\forall v\in N^S.
\]
따라서 $x_{nv}=1$인 substrate node에서 $d_l$만큼의 flow가 생성되고, $x_{mv}=1$인 substrate node에서 동일한 양의 flow가 흡수된다.

\subsection{Load Balancing and Objective Function}
External connectivity는 잔여 자원이 주변 자원과 얼마나 결합될 수 있는지를 평가하지만, 개별 substrate resource의 절대적인 잔여 용량이나 특정 자원으로의 load concentration을 직접 나타내지는 않는다. 이를 보완하기 위해 다음 load-balancing cost를 사용한다.
\[
C_{\mathrm{LB}}(x,f)
=
\alpha
\sum_{n\in N^V}
\sum_{v\in N^S}
\frac{d_n}{r_v+\epsilon}x_{nv}
+
\beta
\sum_{l\in L^V}
\sum_{(u,v)\in A^S}
\frac{f_{uv}^l}
{r_{\{u,v\}}+\epsilon},
\]
여기서 $\alpha,\beta\ge0$는 각각 node와 link load-balancing cost의 가중치이며, $\epsilon>0$는 분모가 0이 되는 것을 방지하기 위한 작은 상수이다. 잔여 용량이 작은 자원에 동일한 demand를 배치할수록 비용이 증가하므로 특정 substrate resource에 부하가 집중되는 것을 억제한다.

최종 목적함수는 load balancing과 induced fragmentation을 함께 고려하여
\[
\min_{x,f}
\quad
J(x,f)
=
C_{\mathrm{LB}}(x,f)
+
\lambda
\Delta F_{\mathrm{frag}}(M),
\qquad
\lambda\ge0
\]
로 정의한다. $C_{\mathrm{LB}}$는 substrate resource의 부하 집중을 억제하고, $\Delta F_{\mathrm{frag}}$는 현재 VNR을 임베딩하는 과정에서 잔여 자원의 external connectivity가 저하되는 것을 억제한다. 따라서 \ecfvne{}는 현재 요청의 resource efficiency와 임베딩 이후의 residual-resource usability를 동시에 고려한다.


\section{ECF-VNE Embedding Algorithm}
\label{sec:embedding_algorithm}

\begin{algorithm}[t]
\caption{ECF-VNE: External-Connectivity-Based Fragmentation-Aware Online VNE}
\label{alg:ecf_vne}
\begin{algorithmic}[1]

\STATE Input:
substrate network $G^S$, arriving VNR $G^V$,
$K$, $\Delta$, $\alpha$, $\beta$, $\lambda$, $\gamma$, $\epsilon$

\STATE Output:
embedding $M$ or \textsc{Reject}

\STATE Obtain virtual-node processing order $Q$
following VNE-RFD~\cite{lu2022resource}

\FOR{each virtual node $n$ in $Q$}

    \STATE Construct feasible substrate-node set $D(n)$
    \STATE $\mathcal{C} \leftarrow \emptyset$

    \FOR{each $v\in D(n)$}

        \STATE Save the current substrate state $S_0$
        \STATE Tentatively map $n$ onto $v$
        \STATE $\mathrm{feasible}\leftarrow\mathrm{true}$,
        $C_L\leftarrow0$

        \FOR{each $l=\{n,m\}\in L^V$ with already mapped $m$}

            \STATE Generate feasible $K$-shortest paths
            $\mathcal{P}_l$ between $v$ and $M_N(m)$

            \IF{$\mathcal{P}_l=\emptyset$}
                \STATE $\mathrm{feasible}\leftarrow\mathrm{false}$
                \STATE break
            \ENDIF

            \STATE Let $S$ be the current tentative substrate state

            \STATE
            $P_l^*
            \leftarrow
            \displaystyle
            \arg\min_{P\in\mathcal{P}_l}
            \left[
                \beta
                \sum_{e\in P}
                \frac{d_l}{r_e+\epsilon}
                +
                \lambda
                \Delta F_{\mathrm{frag}}(S\rightarrow S_P)
            \right]$

            \STATE Tentatively allocate $l$ on $P_l^*$

            \STATE
            $C_L
            \leftarrow
            C_L
            +
            \displaystyle
            \sum_{e\in P_l^*}
            \frac{d_l}{r_e+\epsilon}$

        \ENDFOR

        \IF{$\mathrm{feasible}$}

            \STATE Let $S_{n,v}$ be the resulting tentative state

            \STATE
            $J_{\mathrm{cand}}(n,v)
            \leftarrow
            \displaystyle
            \alpha\frac{d_n}{r_v+\epsilon}
            +
            \beta C_L
            +
            \lambda
            \Delta F_{\mathrm{frag}}(S_0\rightarrow S_{n,v})$

            \STATE Store
            $(v,\{P_l^*\},J_{\mathrm{cand}}(n,v))$
            in $\mathcal{C}$

        \ENDIF

        \STATE Restore substrate state $S_0$

    \ENDFOR

    \STATE Sort $\mathcal{C}$ in ascending order of $J_{\mathrm{cand}}$
    \STATE Apply candidates using the VNE-RFD bounded backtracking procedure

    \IF{no feasible candidate remains or backtracks exceed $\Delta$}
        \STATE return \textsc{Reject}
    \ENDIF

\ENDFOR

\STATE Commit embedding $M$ and update residual substrate resources
\STATE return $M$

\end{algorithmic}
\end{algorithm}



Algorithm~\ref{alg:ecf_vne}은 제안하는 \ecfvne{}의 online embedding 절차를 나타낸다. \ecfvne{}는 VNE-RFD~\cite{lu2022resource}의 online embedding framework를 기반으로 하며, virtual-node processing order, feasible substrate-node candidate generation, $K$-shortest-path search, bounded backtracking 절차를 유지한다. 제안 기법의 핵심 차이는 각 node candidate와 routing path를 평가할 때 load-balancing cost뿐 아니라 앞서 정의한 induced fragmentation cost를 함께 반영한다는 점이다.

현재 처리 중인 virtual node $n$에 대해 알고리즘은 feasible substrate-node candidate $v\in D(n)$를 하나씩 가정한다. Candidate $v$에 $n$을 임시로 배치한 뒤, 이미 매핑된 neighboring virtual node와 연결되는 incident virtual link를 순차적으로 routing한다. 각 virtual link에 대해서는 양 끝점을 연결할 수 있는 feasible $K$-shortest paths를 생성하고, 각 path를 임시로 적용했을 때의 link load-balancing cost와 induced fragmentation cost를 함께 계산한다. 이 두 비용의 합이 가장 작은 path를 선택하여 tentative substrate state에 반영한다.

해당 candidate에 필요한 incident virtual link의 routing이 모두 성공하면 node load-balancing cost, 누적 link load-balancing cost, 그리고 candidate 적용 전후의 induced fragmentation cost를 합하여 $J_{\mathrm{cand}}(n,v)$를 계산한다. Feasible candidate들은 이 점수의 오름차순으로 정렬되며, 가장 낮은 비용의 candidate부터 실제 embedding 후보로 적용된다. 이 과정에서 단순히 현재 단계의 자원 요구를 만족하는 candidate가 아니라, 적용 이후의 residual substrate state까지 고려하여 candidate의 우선순위를 결정한다.

이후 virtual node의 embedding이 불가능해지면 VNE-RFD의 bounded backtracking 절차에 따라 이전 단계로 돌아가 다음 candidate를 선택한다. Backtracking 횟수가 $\Delta$를 초과하거나 더 이상 feasible candidate가 존재하지 않으면 해당 VNR을 reject한다. 반대로 모든 virtual node와 virtual link가 성공적으로 배치되면 전체 embedding $M$을 commit하고 residual substrate resource를 갱신한다.

하나의 induced fragmentation cost를 계산할 때 전체 node fragmentation에는 $O(|L^S|)$의 연산이 필요하다. Link fragmentation은 각 substrate link의 양 끝점에서 인접 link 집합을 평가하므로 전체적으로 $O(\sum_{v\in N^S}(d_v^S)^2)$의 연산이 필요하다. 따라서 한 번의 fragmentation 평가 복잡도는
\[
T_F
=
O\!\left(\sum_{v\in N^S}(d_v^S)^2\right)
\subseteq
O(|N^S||L^S|)
\]
이며, candidate evaluation과 $K$-shortest-path selection 과정에서 이 비용이 반복적으로 추가된다.


\section{Performance Evaluation}
\label{sec:performance_evaluation}

\subsection{실험 설정 및 평가 지표}
제안하는 \ecfvne{}의 online embedding 성능은 VNE-RFD-B, VNE-RFD-D, D-ViNE, R-ViNE와 비교한다. Substrate node의 CPU capacity와 substrate link의 bandwidth capacity는 각각 $U(50,100)$에서 생성한다. 각 VNR은 2--10개의 virtual node를 갖는 connected Erd\H{o}s--R\'{e}nyi graph $G(n,0.4)$로 생성하고, virtual node의 CPU demand는 $U(0,20)$, virtual link의 bandwidth demand는 $U(0,50)$에서 생성한다.

VNR은 Poisson process에 따라 도착하며, holding time은 평균 1,000 time units의 exponential distribution을 따른다. 각 simulation은 초기 과도 상태를 제거한 뒤 steady-state 구간에서 50,000 time units 동안 성능 지표를 집계한다. 주요 평가지표는 VNR acceptance ratio, revenue-to-cost ratio, average CPU utilization, average link utilization이다. Acceptance ratio는 장기적으로 얼마나 많은 요청을 수용할 수 있는지를 나타내며, 나머지 세 지표를 함께 관찰하여 수용률 향상이 embedding cost 또는 substrate resource utilization에 어떤 영향을 주는지 평가한다.

\subsection{실제 Topology Zoo Network에서의 성능}
Synthetic ER graph에서 관찰한 결과가 특정 random topology에 한정되지 않는지 확인하기 위해 Internet Topology Zoo의 실제 network topology를 substrate로 사용한다. 원본 topology에 포함된 parallel edge는 병합하여 simple graph로 변환하고, 규모가 유사한 Palmetto $(45,64)$, Bell Canada $(48,64)$, Surfnet $(50,68)$을 선택한다. 괄호 안의 값은 각각 node 수와 link 수를 의미한다. 세 topology의 규모를 유사하게 유지함으로써 network size 차이의 영향을 줄이고, 서로 다른 실제 연결 구조에 대한 \ecfvne{}의 robustness를 평가한다.

Substrate resource와 VNR generation, holding time, simulation duration, paired sampling 조건은 ER 실험과 동일하게 설정한다. 대신 VNR arrival rate를 1,000 time units당 5, 10, 15, 20, 25개로 변화시켜 workload 증가에 따른 성능 변화를 비교한다.

Revenue-to-cost ratio에서는 VNE-RFD-B와 VNE-RFD-D가 일부 조건에서 더 높은 비용 효율을 보이지만, \ecfvne{}는 그보다 많은 VNR을 수용하면서 높은 CPU utilization을 보인다. Link utilization은 topology와 workload에 따라 서로 다른 양상을 보일 수 있으나, 세 실제 topology에서 \ecfvne{}의 상대적인 acceptance-ratio 우위가 유지된다는 점은 제안한 residual-resource usability 관점이 다양한 substrate 구조에서도 유효함을 보여준다.


\section{Conclusion}
\label{sec:conclusion}

본 논문에서는 online VNE에서 반복적인 임베딩으로 인해 잔여 자원의 총량이 충분하더라도 다른 잔여 자원과 효과적으로 결합되지 못해 향후 요청에 활용하기 어려워지는 resource fragmentation 문제를 다루었다. 이를 위해 잔여 자원의 양뿐 아니라 주변 자원과의 결합 가능성을 external connectivity로 나타내고, 이를 기반으로 잔여 자원의 활용 가능성을 정량화하는 \ecf{} metric을 제안하였다. 또한 node embedding과 link routing에서 요구되는 자원 결합 방식의 차이를 반영하여 node와 link에 대한 fragmentation score를 각각 정의하였다.

임베딩 전후의 fragmentation score 변화에서는 자원 자체가 소비된 효과와 남아 있는 자원의 connectivity가 저하된 효과를 분리하고, 후자를 induced fragmentation cost로 정의하였다. \ecfvne{}는 이 비용을 load-balancing cost와 함께 고려함으로써 현재 VNR의 feasibility와 resource usage뿐 아니라 임베딩 이후 남게 되는 substrate resource의 활용 가능성을 embedding decision에 반영한다.

Erd\H{o}s--R\'{e}nyi substrate의 edge probability를 변화시킨 실험과 Internet Topology Zoo의 실제 network structure를 이용한 실험에서, \ecfvne{}는 서로 다른 substrate connectivity와 VNR arrival-rate 조건에서도 비교 알고리즘보다 높은 VNR acceptance ratio를 일관되게 나타냈다. 일부 조건에서는 개별 embedding의 revenue-to-cost ratio가 VNE-RFD 계열보다 낮게 나타났지만, 더 많은 VNR을 지속적으로 수용하면서 substrate resource를 활용한다는 점에서 제안한 fragmentation-aware embedding의 목적과 일관된 결과를 보였다.

한편 제안 지표는 각 substrate node 또는 link 주변의 local external connectivity를 이용하여 잔여 자원의 결합 가능성을 평가하므로, 외부로 연결되는 여러 경로 사이의 resource-sharing 관계까지 직접 포착하지는 않는다. 서로 다른 boundary link가 이후 동일한 substrate link 또는 bottleneck 구간을 공유하는 경우, 각 지역에서 관찰되는 external connectivity가 높더라도 실제 독립적인 embedding capacity는 제한될 수 있다. 따라서 현재 지표는 residual resource의 local usability를 효율적으로 평가하지만, substrate 전역의 path overlap 또는 shared bottleneck에 의해 발생하는 상호 의존성을 완전히 표현하지는 않는다.

향후 연구에서는 external connectivity를 path overlap, shared bottleneck, 또는 더 넓은 범위의 flow 및 cut structure와 결합하여 이러한 한계를 보완할 수 있다. 특히 online VNE에서 반복적으로 평가할 수 있는 계산 복잡도를 유지하면서 local resource connectivity와 global resource-sharing 관계를 동시에 반영하는 fragmentation metric을 설계하는 것이 중요한 연구 과제가 될 수 있다.
